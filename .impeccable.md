# .impeccable.md

## Design Context

### Project Overview

A Chrome extension popup (600×600px) for tracking video watching history across streaming sites (bilibili, iyf.tv, zxzjhd.com). Core job: quickly see what you've watched and jump back in.

### Tech Stack

- React + TypeScript + Tailwind CSS (default config, no custom tokens yet)
- Chrome Extension popup — fixed 600×600px viewport
- Light/dark mode toggle (both equally important)
- No custom design library; all styles via Tailwind utility classes

### Current Palette

| Token | Dark | Light |
|---|---|---|
| Background | `gray-800` | `slate-50` |
| Surface | `gray-700` | `white` |
| Surface raised | `gray-600` | `gray-200/300` |
| Text primary | `gray-100` | `gray-900` |
| Text muted | `gray-400` | — |
| Accent | `blue-400/500` | `blue-500` |

### Users

Self-use power user who may share with friends. Opens the popup while watching to recall progress, then clicks to resume. Short, goal-oriented sessions — no browsing, no discovery. Context: full-screen video, switching to the popup and back.

### Brand Personality

**Simple · Efficient · Restrained**

The extension should feel like a tool that respects the user's time. No chrome, no fluff. Information surfaces immediately. Actions are obvious but not loud.

### Aesthetic Direction

**Reference: Linear** — precision, depth without darkness, restrained color, strong typographic hierarchy. The popup should feel like a well-made developer tool, not a consumer app.

Anti-references: anything "streamer-y" (neon gradients, heavy imagery, playful fonts). No accent overuse.

Both light and dark modes are first-class citizens. Dark should feel focused and deep (not flat gray). Light should feel clean and airy (not clinical white).

### Design Principles

1. **Information density over decoration** — pack more meaningful signal per pixel; suppress noise (URLs, tracking params, redundant metadata).
2. **Typographic hierarchy carries the UI** — size, weight, and opacity do the heavy lifting. Color is used sparingly, only for interactive or semantic purposes.
3. **Restrained accent** — blue is reserved for links and primary actions only. Group/section headers use neutral tones.
4. **Depth through layering** — use subtle background stacking (3-4 levels) rather than borders or shadows to communicate hierarchy.
5. **Both modes feel intentional** — dark isn't just `color-invert`; each mode has its own sense of atmosphere. Dark = focused cinema feel. Light = clean reading feel.
